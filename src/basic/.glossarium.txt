Render	            : Proses React menghasilkan tampilan dari data yang ada saat itu.

Vite	            : Alat yang menjalankan projek React saat dikembangkan, dan mengemasnya saat akan diterbitkan.
Template	        : Kerangka projek siap pakai. Kelas ini memakai react-compiler-ts.
Dev server	        : Program yang menyajikan aplikasimu selama dikembangkan, dan memperbarui halaman saat kode berubah.
node_modules	    : Folder berisi seluruh paket yang dibutuhkan projek. Tidak pernah disunting tangan.

Komponen	        : Bagian tampilan yang berdiri sendiri, ditulis sebagai fungsi yang menghasilkan tampilan.
Props	            : Data yang dikirim dari komponen di atas ke komponen di bawahnya.
Komponen induk	    : Komponen yang memakai komponen lain di dalamnya.
Komponen anak	    : Komponen yang dipakai di dalam komponen lain.

TSX	                : Cara menulis tampilan di dalam berkas TypeScript, bentuknya mirip HTML.
createRoot	        : Fungsi React yang menentukan elemen mana di halaman yang jadi tempat aplikasi.
StrictMode	        : Pembungkus dari React yang menyalakan pemeriksaan tambahan selama pengembangan.
React Compiler	    : Alat yang berjalan otomatis saat kode diproses, membuat aplikasi tidak mengerjakan pekerjaan yang tidak perlu.

Dev server	        : Program yang menyajikan aplikasimu selama dikembangkan dan memperhatikan perubahan berkas.
Hot reload	        : Mengganti bagian yang berubah di halaman tanpa memuat ulang seluruhnya.
Muat ulang	        : Memulai halaman dari nol. Semua keadaan yang sedang berjalan hilang.

-d	                : Menjalankan container di latar belakang, sehingga terminal kembali bebas dipakai.
exec	            : Menjalankan perintah di dalam container yang sedang menyala.
build	            : Menyiapkan ulang container dari Dockerfile. Dibutuhkan setelah package.json berubah.
dependencies	    : Daftar paket yang dibutuhkan aplikasi, tersimpan di package.json.

TypeScript	        : JavaScript ditambah keterangan tentang bentuk data. Keterangannya hilang saat kode diproses.
Tipe	            : Keterangan tentang bentuk sebuah nilai, misalnya teks atau angka.
undefined	        : Nilai yang muncul waktu sesuatu yang dicari tidak ada.
Console	            : Tab di alat pengembang browser tempat hasil console.log dan pesan error muncul.

Anotasi tipe	    : Keterangan tipe yang ditulis sesudah titik dua, misalnya const age    : number.
Inferensi tipe	    : Kemampuan TypeScript menebak tipe sendiri dari nilai yang diberikan.
Literal type	    : Tipe yang isinya satu nilai tertentu, misalnya 'Indonesia' dan bukan string.
noUnusedLocals	    : Pengaturan yang menandai variabel yang dibuat tapi tidak pernah dipakai.

type	            : Cara memberi nama pada sebuah bentuk data supaya bisa dipakai berulang.
interface	        : Bentuk lain untuk tujuan serupa, cuma untuk objek. Tidak dipakai di kelas ini.
Product[]	        : Array yang isinya Product semua.
import type	        : Bentuk impor untuk sesuatu yang isinya cuma keterangan tipe.

Union type	        : Tipe yang isinya beberapa kemungkinan, dipisah garis tegak.
Properti opsional   : Properti bertanda tanya, yang boleh tidak ada.
undefined	        : Nilai yang muncul waktu sesuatu yang dicari tidak ada.

Penyempitan tipe	: Kemampuan TypeScript mempersempit kemungkinan tipe di dalam cabang pemeriksaan.
??	                : Memakai nilai di kanan kalau yang di kiri undefined atau null.
**`\	\	`**	    : Memakai nilai di kanan kalau yang di kiri dianggap tidak benar, termasuk teks kosong dan nol.

Parameter	        : Isian yang diterima fungsi, ditulis di dalam kurungnya.
Tipe kembalian	    : Tipe nilai yang dihasilkan fungsi, ditulis sesudah kurung tutup.
void	            : Tipe untuk fungsi yang tidak mengembalikan nilai berguna.
Tipe fungsi	        : Bentuk seperti (value: number) => string, dipakai waktu fungsi jadi isian fungsi lain.

any	                : Tipe yang mematikan seluruh pemeriksaan pada nilai itu dan turunannya. Dilarang di kelas ini.
unknown	            : Tipe untuk nilai yang bentuknya belum diketahui, dan menuntut pemeriksaan sebelum dipakai.
Penularan tipe	    : Nilai yang diambil dari nilai bertipe any ikut bertipe any.

Generic	            : Tempat kosong untuk sebuah tipe, diisi waktu dipakai. Ditulis di dalam kurung siku.
T	                : Nama yang lazim dipakai untuk tempat kosong itu, dari kata type.
Array<string>	    : Bentuk panjang dari string[]. Artinya sama persis.
useState<Product[]>	: Bentuk yang paling sering kamu tulis di React, waktu nilai awal state-nya kosong.

assignable	        : Kata di pesan error yang menandai perbandingan dua tipe. Kiri yang diberikan, kanan yang diminta.
npm run build	    : Perintah yang memeriksa tipe seluruh projek sekaligus, sampai ke berkas yang sedang tidak kamu buka.
verbatimModuleSyntax: Pengaturan yang menuntut impor tipe ditulis dengan import type.

Komponen	        : Fungsi yang mengembalikan tampilan. Namanya selalu diawali huruf besar.
TSX	                : Bentuk penulisan tampilan di dalam berkas TypeScript. Terlihat mirip HTML.
.tsx	            : Akhiran berkas yang boleh memuat TSX. Berkas .ts biasa tidak bisa.
export default	    : Menandai satu hal utama di sebuah berkas supaya bisa dipakai berkas lain.

Default export	    : Satu hal utama per berkas. Diimpor tanpa kurung kurawal.
Named export	    : Bisa banyak per berkas. Diimpor dengan kurung kurawal, nama harus sama.
Jalur relatif	    : Jalur yang dihitung dari berkas yang sedang ditulis. Diawali titik.

Ekspresi	        : Apa pun yang menghasilkan nilai. Boleh masuk ke dalam kurung kurawal.
Pernyataan	        : Perintah seperti if dan for. Tidak menghasilkan nilai, jadi tidak boleh.

Komponen anak	    : Komponen yang dipakai di dalam komponen lain.
